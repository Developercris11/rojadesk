# Scripts Archive

Archivos de scripts antiguos y descontinuados que se mantienen por referencia.

## Contenido

### Analysis Scripts (analyze_*.js)
- `analyze_abbeville_page.js` - Análisis página de Abbeville
- `analyze_alabama_page.js` - Análisis página de Alabama
- `analyze_alm_directory.js` - Análisis directorio de municipios
- `analyze_alm_structure.js` - Análisis estructura de datos

### Scraping Scripts (scrape_*.js)
- `scrape_alabama_cities.js` - Scraping inicial de ciudades de Alabama
- `scrape_alabama_detailed.js` - Scraping detallado de ciudades
- `scrape_alm_*.js` - Múltiples versiones de scraping de directorio de municipios

### Import Scripts (import_*.js)
- `import_alabama_direct.js` - Importación directa de datos
- `import_alabama_municipalities.js` - Importación de municipios

### Utility Scripts
- `extract_cities.js` - Extracción de ciudades
- `check_db.js` - Verificación de base de datos
- `manual_migrate_leads.js` - Migración manual de leads

## Uso

Estos scripts están aquí por referencia. Para versiones activas, ver:
- `scripts/` - Scripts activos del proyecto
- `src/app/api/v1/scraping/` - API de scraping moderna

## Notas

- No usar directamente en producción
- Servir como referencia para nuevas implementaciones
- Revisar antes de eliminar
