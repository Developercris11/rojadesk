# Debug Scripts

Scripts para debugging y desarrollo.

## Debug Files

- `debug-extractor.js` - Debugging de extractor de datos
- `gmaps_test.js` - Testing de Google Maps integration
- `tmp_inspect_findyello.js` - Inspección de datos Findyello
- `tmp_inspect_findyello_profile.js` - Inspección de perfiles Findyello

## HTML Exports

- `tmp_bbb_debug.html` - Export HTML para debugging BBB

## Logs

Ver carpeta `logs/` para archivos de log

## Uso

Estos scripts se usan durante desarrollo y debugging.

```bash
node scripts/debug/gmaps_test.js
```

## Limpiar

Después de usar, pueden ser eliminados.
