# Logs

Archivos de log del proyecto.

## Archivos

- `build_error_new.txt` - Error de build
- `debug_v1_activity.txt` - Actividad de debug v1
- `dev_log.txt` - Log de desarrollo
- `prisma_err.log` - Error de Prisma
- `prisma_out.txt` - Output de Prisma
- `server_debug.log` - Log de debug del servidor
- `dump.txt` - Dump de datos
- `server_debug.log` - Log del servidor

## Limpiar

Los logs pueden ser deletreados periódicamente.

```bash
# Limpiar todos los logs
rm logs/*.log logs/*.txt
```

## Nuevo Proyecto

Para nuevo proyecto, estos logs no son necesarios.
Generar nuevos durante desarrollo.
